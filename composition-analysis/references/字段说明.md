# 结果 JSON 字段说明（给调用 Skill 的 agent）

完整示例见 `结果JSON模板.json`。所有路径相对 `config.json` 的 `workspace_root`，也可写绝对路径。

## 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 否 | 网页面板标题，默认「构图分析 · 21 类判断卡」 |
| `images` | 是 | 非空数组，一轮 1–8 张 |
| `usage` | 否 | 用途建议对象；不给则网页显示「本次未指定用途」 |

## `images[]`

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 图 1、图 2… 只作索引，不要用文件名 |
| `image_path` | 是 | 原图路径，渲染器只读、不改动 |
| `pixels` / `desc` | 否 | 原始像素、一句画面描述 |
| `main` | 是 | `{name, key, confidence, evidence}`。`key` 必须是 21 类里的 key；属于 `asym_balance / radial / golden / perspective` 时网页自动打「网页引擎未支持」标签 |
| `aux` | 是 | 数组，**最多 3 个**，每项 `{name, strength, evidence}`；没有就 `[]` |
| `position` | 是 | 对象，键自定义（主体位置与占比 / 引导线 / 留白 / 前中后景 / 视觉平衡），值写画面事实 |
| `confuse` | 是 | 数组，每项 `{name, reason}`，写易混类别与排除理由；没有就 `[]` |
| `uncertain` | 否 | 类别重叠、弱证据、证据不足的说明 |
| `layers` | 是 | 分层标签对象；其中 `拍摄角度（人工参考）` **必须写「未标注」** |
| `annotations` | 是 | 标注坐标对象，见下 |
| `annotation_note` | 建议 | 说明框线是视觉估计、对应画面哪条线／哪块空域 |
| `cases` | 是 | 数组，**最多 2 个**；没有合适案例写 `[]` |
| `case_note` | 否 | 如「本图无合适图库案例，未硬配」「只做结构形态对照」 |
| `reverse_prompt` | 否 | 用户明确要求反推提示词时填写；未要求时为 `null` 或省略。对象结构见下方 |

## `cases[]`（只写 3 个字段）

| 字段 | 说明 |
|---|---|
| `num` | 图库编号，写 `"225"` 或 `"#225"` 都行；**必须存在于 `assets/gallery/gallery_manifest.json` 的 `display_id`** |
| `similar` | 按画面写相似点 |
| `different` | 按画面写不同点 |

主构图、题材、**来源类型**、作者、许可、作品来源页与图片文件全部由 `render.py` 从 manifest 精确读取，agent 不要填，也不要凭来源标题判断类别。

## `annotations`（归一化 0–1）

| 字段 | 说明 |
|---|---|
| `subject_box` | `[x0, y0, x1, y1]`，主体大致范围，橙框 |
| `lines` | `[{from:[x,y], to:[x,y], label:"…"}]`，构图线，蓝线带箭头；只画承担结构作用的线 |
| `regions` | `[{rect:[x0,y0,x1,y1], label:"…", type:"negative"}]`，留白或关键结构区域，绿虚线 |
| 没有就留空数组 | 渲染器不画任何东西，但网页仍会显示图例与「视觉估计示意」说明 |

坐标是**看图时的近似示意**，不是像素级检测，也不能当测量数据用。

## `usage`

| 字段 | 说明 |
|---|---|
| `given` | 用户给的用途；没给写「未指定用途（条件性比较）」 |
| `advice` | 该用途下的结论；条件性比较要写明「不合并总排名」 |
| `basis` | 画面事实依据 |
| `alternatives` | 其它用途各自的条件性结论，字符串数组；没给用途时建议列 2–3 条 |

用途建议与构图判定在网页里是两个独立区块，**不要互相推导**：有可压字空域 ≠ 留白构图是主结构；挑商品图 ≠ 符合平台主图规范。

## `reverse_prompt`（可选）

仅在用户要求看图反推生图提示词时填写。字段结构和判读口径见 `反推提示词指南.md`。

| 字段 | 必填 | 说明 |
|---|---|---|
| `mode` | 是 | `忠实复现视觉效果`、`保留主体换场景`、`借用构图做新图` 等 |
| `host_ai` | 是 | 当前接收图片并运行 Skill 的助手；不可见具体模型时写未知，不猜测 |
| `target_ai` | 是 | 用户指定的生图工具；未指定写「未指定（交付 GPT 细致版与跨平台通用版）」 |
| `adaptation_note` | 是 | 说明采用何种格式以及未使用哪些未验证的专属语法 |
| `fixed_values` | 是 | 固定项数组：`[{"label":"主体身份","value":"…"}]`，只描述应保留内容 |
| `editable_values` | 是 | 可改项数组：`[{"key":"background","label":"背景","value":"…","hint":"可改为…"}]`；`key` 用英文字母/数字/下划线 |
| `prompt_gpt_template` | 是 | GPT 友好的详细中文提示词模板；用 `{{key}}` 插入可改项 |
| `prompt_universal_template` | 是 | 不依赖专有语法的跨平台自然语言模板；使用同一组 `{{key}}` |
| `negative_prompt` | 是 | 可选负面约束；若目标工具无独立负面框，可合并到主提示词的「避免」段 |

工作台会将固定项单独展示，把可改项显示成输入框；编辑值时两版提示词同步更新，可复制后粘贴到目标生图工具。模板占位符必须与 `editable_values[].key` 一致。

## 渲染器会自动做的事

- 校验字段、辅助结构 ≤3、案例 ≤2、角度「未标注」、案例编号存在、原图存在；不通过会直接报错退出，不会生成半成品网页。
- 生成标注图到 `构图分析_结果/_标注图/`。
- 把原图、标注图、案例图转成内嵌 data URI，脱离目录也能打开。
- 只读原网页 `构图工具/构图对比工具.html`，注入面板后写出 `构图工具/构图分析工作台.html`。
- 归档结果 JSON 到 `构图分析_结果/<时间戳>.json` 与 `最新结果.json`。
