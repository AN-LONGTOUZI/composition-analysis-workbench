# 看图反推生图提示词指南

用户要求「反推提示词」「按这张图写 prompt」「复刻这张图」时读取本文件。这里的反推是从图像可见信息重建一份可执行的新提示词，**不是恢复原作者的真实提示词**。

## 1. 先区分两个 AI

| 字段 | 含义 | 使用规则 |
|---|---|---|
| 宿主 AI | 当前接收图片并运行 Skill 的助手，例如 WorkBuddy、Codex、ChatGPT 或豆包 | 只按当前对话中明确可见的信息记录；看不到具体模型时写「当前环境未暴露具体模型」 |
| 目标生图工具 | 用户接下来要粘贴提示词并生成图片的工具 | 用户明确指定时按该工具组织；未指定时默认提供「GPT 细致版」和「跨平台通用版」 |

静态网页不能侦测电脑上正在打开的其它 AI，也不能读取其隐藏模型名、接收图片或直接控制它。Skill 在不同 AI 对话中运行时，使用该对话可见的图片理解能力；提示词的目标平台由用户指定，或按未指定时的默认双版本交付。不要把「能写适配提示词」说成「已连接、已调用目标模型」。

## 2. 反推工作顺序

1. **描述可见事实**：主体是什么、数量与相互关系、画面方向、主体在画面中的位置和占比、裁切方式、背景元素、线条/几何关系、明暗、颜色、质感、可辨识文字。
2. **识别用户意图**：忠实复现视觉效果、保留主体但换场景，或只借用构图/风格。用户没说明时，默认「保留主要主体和构图，重建整体视觉效果」，并把这个默认值写出来。
3. **设定固定项和可改项**：固定项写图像证据和必须保留内容；可改项写默认值、可替换建议。商品图优先锁定商品轮廓、比例、颜色、材质、接口/按键、刻度/纹理和配件，除非用户明确允许改动。
4. **生成两版提示词**：GPT 细致版以清晰分段和完整约束为主；跨平台版使用自然语言，不依赖某一家模型的权重、命令或隐藏参数。两版使用同一组固定项和可改项。
5. **单列负面约束**：写成自然语言、可直接复制的避免项。提醒用户：目标平台若不支持独立负面提示框，把它接到主提示词末尾的「避免」段即可。
6. **说明不确定性**：如内容模糊、被遮挡、文字不可读、镜头信息不可见，标记为推测或不描述；不要补造品牌型号、拍摄设备、焦距、原作者工作流或生成模型。

## 3. 意图模式与锁定策略

| 用户意图 | 默认固定项 | 默认可改项 |
|---|---|---|
| 忠实复现 | 主体身份、主体数量、主要构图、主体位置比例、背景关系、主要光线、主色和材质风格 | 画幅比例、清晰度描述、少量装饰细节；任何改变构图或背景的选项都要标成可选，不得悄悄改变默认 |
| 保留主体、换场景 | 主体/产品身份和辨识细节、主体数量、用户指定的构图约束 | 场景、背景、道具、配色、光线、画幅和氛围 |
| 借构图做新图 | 主体在画面中的位置关系、视线/引导线/留白/景深层次等用户要求借用的结构 | 主体题材、环境、物件、风格、颜色、文字和画幅 |

按用户当下的明确要求调整优先级。用户要求「产品不能变形」时，将产品外观作为不可改约束；不得为了风格迁移重画表盘、商标、接口、包装结构或服装款式。

## 4. 输出给用户的结构

用户只要提示词时直接在对话中给出；不要求本地文件访问或 Python。建议按此顺序输出：

1. **图像拆解**：一句话说明主要画面结构与风格证据。
2. **反推口径**：说明选择的意图模式、宿主 AI 与目标生图工具；看不到的模型名明确写未知。
3. **固定项｜尽量不要改**：逐条列出主体身份、构图关系、外观/色彩/材质等图像事实。
4. **可修改项｜改了会改变什么**：每项提供当前默认值和 1–3 个替换方向。优先覆盖：主体、背景/场景、画幅比例、配色、风格强度、画面文字、光线氛围。
5. **GPT 细致版提示词**：可直接复制。写清画面主体、位置与占比、构图关系、镜头/视点（仅描述可见视角）、空间层次、光线、调色、材质、细节、画幅、保留项和避免项；用自然语言，不用虚构的模型参数。
6. **跨平台通用版**：更紧凑但保留核心约束；不含 `--ar`、`--style`、`::`、权重括号、采样器名等平台专属语法。用户指定目标平台并确需特定语法时，再按官方文档核实后另给适配版。
7. **负面约束**：另列可选内容，例如主体变形、比例错误、额外肢体/物件、错误文字、低清晰度、过度滤镜、未经要求的水印。

## 5. 结果 JSON 结构

只有用户要求在本地工作台查看，且宿主能读写文件并运行 Python 时，才将同一内容写入每张图片的 `reverse_prompt`。完整字段说明见 `字段说明.md`。

```json
{
  "mode": "忠实复现视觉效果",
  "host_ai": "当前环境未暴露具体模型",
  "target_ai": "未指定（交付 GPT 细致版与跨平台通用版）",
  "adaptation_note": "两版使用同一组画面事实；目标工具未指定，因此不含平台专属语法。",
  "fixed_values": [
    {"label": "主体身份", "value": "只按图中可见特征描述的主体"},
    {"label": "构图关系", "value": "主体偏右，左侧留出连续空域"}
  ],
  "editable_values": [
    {"key": "aspect_ratio", "label": "画幅比例", "value": "3:4", "hint": "可改为 1:1、4:5 或 9:16"},
    {"key": "background", "label": "背景场景", "value": "浅暖灰色摄影背景", "hint": "可换成室内、街景或纯色背景"},
    {"key": "overlay_text", "label": "画面文字", "value": "不添加额外文字", "hint": "可填写标题，也可保留无字"}
  ],
  "prompt_gpt_template": "生成一张 {{aspect_ratio}} 画幅的图片……背景使用 {{background}}。{{overlay_text}}。",
  "prompt_universal_template": "创作 {{aspect_ratio}} 画幅图像……背景为 {{background}}；{{overlay_text}}。",
  "negative_prompt": "避免主体变形、比例错误、无关物件、错误文字和水印。"
}
```

`editable_values[].key` 只用英文字母、数字与下划线；提示词模板用 `{{key}}` 引用，对应表单字段可在网页内编辑。不要把固定项做成可编辑输入。固定项/变量只用于提示词编辑，不代表模型会百分之百遵守。

## 6. 两版的写法

### GPT 细致版

- 优先用自然中文完整说明图像目标，不靠堆形容词或无意义的「8K、极致、完美」词汇。
- 把主体身份、构图位置、主体占比、背景、光线、色彩、材质、景深、画面文字和输出比例分别写清楚。
- 对商品/人物等身份敏感主体，设置独立的「必须保留」段；再写「允许调整」与「不要改变」段。
- 为不同用途调节画面：封面写清标题区；商品细节图强调产品完整与细节；风格练习可强调色调、光影、质感。用途未提供就不自行替用户选。

### 跨平台通用版

- 以 1–3 段自然语言表达主体、布局、场景、光影、风格和输出要求。
- 画幅用「竖版 3:4」等文字描述；用户指定平台后，再把比例转换成目标工具的当前语法。
- 把负面约束单独列出。若工具只有一个输入框，合并为「避免……」自然语言句子。
- 不假设其它模型接受 GPT 的格式；不根据平台名称编造参数或宣称已在该工具验证。

## 7. 自查清单

- 没把可见事实和猜测混在一起；没声称找回了原始 prompt。
- 没有身份保留与原创身份等相互冲突的硬要求；目测坐标标作估计，场景推测与原图证据分开。
- 删除重复的禁词，排除项只保留对本图最关键的错误风险；没有把猜测出的品牌、路牌或环境设施写成已确认事实。
- 输出里包含固定项、可改项、默认值和替换方向。
- GPT 版足够详细，通用版不依赖专属参数；两版没有互相矛盾。
- 用户的明确保留要求没有被风格词覆盖；任何可能改变主体身份的内容都先问清或默认锁定。
- 未指定目标平台时说明默认提供双版本；未识别出模型时不声称自动检测。
- 没有调用生图模型，除非用户明确要求直接生成图像。
