# 21 类构图结构速查

本项目使用的结构名称、顺序、定义、判断证据、易混类别和排除条件，以 [21类构图判断卡.md](21类构图判断卡.md) 和对应 JSON 为准。请勿用通用摄影教材里的另一套编号替换项目分类。

| 编号 | Key | 项目分类 | 主要观察点 |
|---:|---|---|---|
| 01 | `center` | 中心构图 | 主体重心接近中轴与中心，周围空间较均衡；单纯居中不等于对称 |
| 02 | `thirds` | 三分法 | 主体、视线或关键线接近三分线/交点；单一方向线索可作弱辅助证据 |
| 03 | `symmetry` | 对称构图 | 沿中轴或水平轴出现近似镜像、成对对应 |
| 04 | `diagonal` | 对角线构图 | 贯穿画面的斜向主线与主体位置共同形成动势 |
| 05 | `vertical` | 垂直线构图 | 多条竖线组织主体，形成秩序、挺拔或纵向延伸 |
| 06 | `horizontal` | 水平线构图 | 水平线分层并组织画面重心 |
| 07 | `curve` | 曲线构图 | 弧线或曲线路径承担主要视觉引导 |
| 08 | `frame` | 框架式构图 | 门窗、拱门、枝叶等围出内框并强调主体 |
| 09 | `guide` | 引导线构图 | 道路、栏杆、边缘等将视线带向主体或远处 |
| 10 | `layers` | 前景层次构图 | 前景、中景主体、背景形成清晰空间层次 |
| 11 | `contrast` | 对比构图 | 明暗、色彩、大小、形态等对比承担主要组织作用 |
| 12 | `negative` | 留白构图 | 大面积简洁空间是画面组织核心；可压字空域本身不足以判为留白构图 |
| 13 | `fill` | 填充画面 | 主体或纹理充满大部分画面，边缘空间有限 |
| 14 | `pattern` | 重复与韵律 | 重复的物体、形状或间距形成节奏 |
| 15 | `triangle` | 三角形构图 | 主体或多元素形成稳定的三角关系 |
| 16 | `split` | 分割构图 | 明确分区、边界或面板结构组织画面 |
| 17 | `flatlay` | 平铺构图 | 多个对象以平面化方式排列成整体；不据此推断相机角度 |
| 18 | `asym_balance` | 非对称均衡构图 | 不同元素以位置、面积、明暗或色彩形成视觉配重 |
| 19 | `radial` | 放射／径向构图 | 线条或形体由中心向外扩散或向中心汇聚 |
| 20 | `golden` | 黄金比例／黄金螺旋构图 | 需要可见螺旋/比例证据或可核对网格；不能凭观感硬判 |
| 21 | `perspective` | 透视汇聚／消失点构图 | 平行线向远处明显收束，建立深度和消失点 |

## 判读边界

- 每张图选择 1 个证据最强的主结构；辅助结构按原判断卡规则标强度，不为凑数硬判。
- 先检查判断卡的“不能判成这一类的情况”，再根据画面证据分类。案例编号和来源类型须从图库索引读取。
- 机位高低、俯拍/仰拍、景别、镜头畸变、题材与设计版式是独立标签，不取代构图类别。
- 网页规则引擎与 Skill 视觉判读的支持范围须分别说明；不要把 21 类判断卡说成网页已能自动识别 21 类。
