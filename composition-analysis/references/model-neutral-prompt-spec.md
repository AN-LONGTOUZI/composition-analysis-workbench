# 跨模型提示词规范

## 目的

先写一份任何图像模型都能读懂的自然语言版本，再按用户指定平台转换输入格式。统一表达主体、位置和关系，比堆模型专属关键词更重要。不同模型对图像参考、文字、比例、负面约束的处理不同，因此提示词只能提高一致性，不能保证相同输出。

## 推荐编排

按任务选择需要的段落，不必机械填满每一项：

1. **画布与整体布局**：横/竖/方、近似宽高比、单图/网格、每格数量和分隔方式。
2. **主视觉与优先级**：最先看到什么；主体落在哪个区域、大小约占多少；视觉焦点在哪里。
3. **主体状态**：外观、动作、朝向、视线、表情、姿态；哪些特征必须保持一致。
4. **对象关系**：前后距离、遮挡关系、方向、相对大小、哪些东西不能重叠。
5. **环境分层**：前景、中景、背景；建筑、道路、人群、自然元素各自的位置和作用。
6. **构图与视角**：主/辅构图、机位高低、拍摄距离、景别、透视强弱、镜头畸变程度。只有图中看得出时才描述具体镜头效果，不猜具体焦距。
7. **光线与色彩**：光源方向、硬/柔、明暗、冷暖关系、主色和点缀色。
8. **质感与风格**：摄影、插画、胶片颗粒、清晰度、景深、运动模糊等。区分内容特征与风格推断。
9. **准确文字**：只在用户明确需要时引用指定文案；描述文字位置、语言、大小写。无法保证模型准确排字时提示后期排版。
10. **约束与排除项**：只写与本图风险相关的错误，如主体重复、结构错位、额外肢体、错误遮挡、意外 UI/水印等。

## 空间锚点写法

- 使用画面相对位置：左上、右下、中央偏左、靠近底边、约占画面下半部。
- 对精细定位可用近似百分比或归一化区域，例如“中心约在画面宽度 50%、高度 58% 处，估计误差约 5%”。没有明显边界时不要伪精确。
- 明确主次顺序：例如“猫脸是第一视觉焦点，伸向镜头的前爪是第二焦点，女人在左侧中景”。
- 明确层次与遮挡：例如“人处于猫后方左侧，与猫脸之间留出可见间隔；不遮挡主体五官”。
- 透视、景深、运动模糊分开讲：例如“地面边缘轻微运动模糊，主体保持清晰”。
- 把“必须保持”和“可变化”分开：锁定布局、主体关系、数量和关键道具；允许材质细节、背景路人数量、轻微色调变化。

## 画幅和分格的几何校验

若网格有 `C` 列、`R` 行，每格宽高比为 `r = 宽 / 高`，且格子尺寸相同、没有额外留白，则整体宽高比为：

`整体宽高比 = (C / R) × r`

示例：2 列 × 2 行，每格 3:4（即 `r = 3/4`），整体也是 3:4，不可能同时是 9:19。要做 9:19 的 2×2 拼图，单格约需 9:38，画面会非常窄长；或者保留 3:4 单格，改整体比例/网格布局。若有边距、间隔或不等宽格子，要用实际总画布尺寸重新校验。

先向用户解释冲突，再给可执行选项。若用户明确让你决定，选择最贴近参考图视觉目标的方案，并简述假设。

## 多格拼图

- 先写整体网格（列数、行数、阅读顺序、分隔线/留白）。
- 写一段共享角色/商品一致性锚点：发型、服装、色彩、身份或物品结构。
- 每格独立描述：机位、景别、动作、主体位置、手部/道具关系、局部背景。不要只写“类似参考图的其他角度”。
- 写明每格之间的连续性要求，以及每格需要变化的内容。
- 所有面板比例与整体画布比例经校验后再输出。
- 对难生成的四格连贯图，建议把提示词拆成四张单图生成，再拼版；如果用户希望一次生成则保留整体提示词，并说明模型可能无法稳定维持面板边界和身份连续性。

## 跨工具适配

- **通用版**：中文自然语言，完整表达画面事实和关系，默认直接可复制。
- **指定平台版**：用户点名平台后再调整分辨率/比例选项、参考图用法、负面提示词栏和平台特有语法。平台能力可能更新；不确定就提示用户以界面选项为准，不编造参数。
- **有参考图的生成**：区分“用图像作为主体/身份/产品参考”和“只借用构图/色彩/气氛”。避免无意复制人物身份、商标或未经授权内容。
- **自动水印**：水印是工具的来源标记，不应写进期望画面。文字提示不能保证平台去掉自动水印；可在平台导出设置中查看正规选项。
- **负面提示**：有独立负面提示框时可拆分；没有时用简洁自然语言说明避免项。避免长串同义禁词影响主体描述。
- **提示词长度**：用户偏好详细时先保留完整锚点，再删除重复形容词。不能因为变短而丢掉位置、数量、前后关系、透视和布局约束。

## 输出前一致性自检

- **检查互相冲突的要求**：例如“保留同一位真实人物的全部面貌”与“改成原创虚构人物、不复刻身份”不能同时作为硬约束。用户要原创人物时，只借用明确允许的发型、服装、姿势或色彩，不要求复现真实身份；若用户要忠实保留人物，则不要同时写成完全不同的身份。
- **检查数字是否有依据**：主体坐标或占比只有在图像中确有帮助且已目测/测量时才写；目测数字标作近似估计，通常用区间或约数，不写看似精确但未经核对的边界。
- **检查场景元素是否来自图像**：把可见事实写进固定项；推测、建议新增的路人、车辆、标牌、地面设施等放入可修改项，不能当作原图证据。
- **合并重复约束**：同一条“不要文字/水印/界面”只保留一次；负面约束聚焦本图最可能出错的 3–6 项，避免正向要求和避免项互相打架。
- **检查详略层级**：先确保主体、布局、空间关系、机位与画幅准确，再补色彩、材质和氛围；不靠重复形容词或无依据的镜头参数增加长度。

## 生成结果复核表

将参考图与结果按下列项目对照，逐项写“符合 / 部分符合 / 未符合”和可见证据：

| 项目 | 核查内容 |
|---|---|
| 整体结构 | 画幅、网格、阅读顺序、主体主次 |
| 位置比例 | 主体中心、占比、离边距离、元素间距 |
| 动作关系 | 姿态、朝向、视线、道具握持或衔接 |
| 空间透视 | 前中远景、机位、消失点、近大远小 |
| 环境锚点 | 建筑、道路、人群、海面等是否在正确区域 |
| 光色质感 | 光源方向、冷暖、对比、锐度、运动模糊 |
| 文字与界面 | 指定文案是否正确；是否意外带入 UI 或生成标记 |
| 结构完整性 | 数量、肢体、手爪、物件结构、重复元素 |

复核时优先改最影响相似度的 1–3 个问题，避免每轮同时改很多条件。生成水印单独记作来源信息，不作为构图还原失败项。

## 实测校准提示

以下是有限实测案例的校准结论，只能在当前上传图确实呈现相同元素和关系时用作参考；不得把它们当作其他图像的默认内容或观察事实。

- **猫冲刺案例**：明确“猫脸第一焦点、爪子近大、人物在左后中景、鱼从嘴向右下延伸”比单说“夸张超广角”更清楚。
- **海边咖啡店案例**：对称轴、门窗和招牌的垂直排列、建筑完整入画、海平线位置比“梦幻清新”更能锁定结构；文字和空调位置需要单独说明。
- **四格街拍案例**：先定网格和每格比例，再逐格描述机位、动作和手部位置；共享服装与发型作为连续性锚点。
- **跨工具样图**：本轮 WorkBuddy（WB）与豆包样图呈现出主要画面关系，同时也出现细节、色调和镜头夸张程度差异。将各自可见的水印标记为来源，不混入反推提示词。
- 以上为有限样例观察，不代表平台普遍性能排序，也不能据此承诺未来输出。
